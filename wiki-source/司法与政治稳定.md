# 司法与政治稳定

最高司法机关名称随政体变化。提高独立性可能带来更多审查互动；压低独立性则可能引发支持、稳定和持续局势风险。

<a name="concept-judiciary"></a>

## 最高司法机关

国家最高法律审查机构，名称随政体变化。可通过互动、任命和事件影响其独立性；高独立提供制度制衡，也会增加司法审查与互动。

**同义词 / 可搜索词：** 最高法院、宪法委员会、联邦最高法院、最高宗教宪法法院、最高人民法院、王国最高审判院、贵族最高裁判庭、国家最高裁判庭、最高教法审判庭

<a name="concept-judicial"></a>

## 司法独立

范围0至100。低于35每季支持−2、稳定−2，低于20时各−3；降至20可触发司法公平事件。连续高位会提高司法互动频率。保障任期和预算、法治型任命与事件选择可提高独立性，行政干预会降低它。

**同义词 / 可搜索词：** 司法独立度、独立性、独立性连续高位、司法互动概率

<a name="concept-judicial-pressure"></a>

## 司法干预

行政机关施压司法的记录。可以短期争取配合，但会降低独立性，增加政治风险，并影响选举争论及统治倾向评估。

**同义词 / 可搜索词：** 司法干预历史、行政施压

<a name="concept-court-actions"></a>

## 司法互动

与最高司法机关沟通或调整制度保障。各项行动的即时效果在按钮中列明，通常消耗1点行动点。

**同义词 / 可搜索词：** 与最高司法机关互动

<a name="concept-constitution"></a>

## 宪法

国家档案记载政体、竞争性选举条文、任期、经济模式、司法机关、公民权利与预算上限。所有修宪先经议事机关三分之二表决，再经三季度司法审查。非民主国家可通过竞争性选举条文转型。

**同义词 / 可搜索词：** 重要宪法条目内容、宪法条目、根本法

<a name="concept-judges"></a>

## 法官席位

每局随机 5—10 席，其中一位首席，每人一票。社会进步与政治自由两类合计少于半数。扇形座位颜色显示倾向，星号表示首席。

**同义词 / 可搜索词：** 法官、大法官、首席大法官、宪法委员、宪法委员会主席、联邦大法官、联邦首席大法官、宗教宪法法官、首席宗教宪法大法官、审判员、最高人民法院院长、王国审判官、王国首席审判官、贵族裁判官、最高裁判长、国家裁判官、国家首席裁判长、教法审判官、首席教法审判长

<a name="concept-constitutional-docket"></a>

## 修宪与释宪

所有修宪从议事机关的议长／主席处提出，消耗1行动点并进入宪法修订局势。先取得至少三分之二院内支持（表决1行动点），再提交最高司法机关。送审后最多3季度，赞成达到半数立即成功；到第3季度开始时仍不足半数则失败。恰好50%的司法赞成票也能通过。局势无特殊处置选项；不能强行修宪。释宪保留原路径和超过50%的门槛。

**同义词 / 可搜索词：** 修宪、释宪、宪制议案、请求释宪、提出修宪、宪法修订、司法审查

<a name="concept-judge-interaction"></a>

## 法官互动

每位法官每季可互动一次。意愿达到 60 则投赞成票；游说加成仅对当前议案有效，至操作季度加 3 季度后失效。公开论证无风险；贿赂／政治交换下一季分别有 3%／2% 概率触发政治丑闻；施压下一季有 3% 概率追加司法独立 −10 的特殊事件，不占三个常规事件名额。

**同义词 / 可搜索词：** 贿赂、政治交换、司法压力、公开法律论证、法官支持率、法官意愿

<a name="concept-constitutional-budget"></a>

## 预算上限

释宪可使选定公共预算的上限增加 1 个百分点，最高为 100%。实际支出仍以通过的预算案为准。释宪通过时支持 −1、稳定 −2。

**同义词 / 可搜索词：** 公共预算上限、国家对劳动者的义务

<a name="concept-constitutional-reform"></a>

## 改革成本减免

仅能选择当前改革窗口中尚未启动的草案。释宪会保留草案，每次减少原价的 25%，累计最多 50%。实际减免在改革正式表决通过并启动时兑现。已启动或完成的改革不能补领减免。

**同义词 / 可搜索词：** 释宪减免、公共利益解释

<a name="concept-constitutional-transfer"></a>

## 最高司法权移交

移交最高司法权的修宪同样需要先获议事机关三分之二支持，再经当前最高司法机关半数赞成。生效时司法独立−20、稳定−10、支持+10。移交后，释宪及后续修宪的司法审查由获授最高司法权的机关办理。

**同义词 / 可搜索词：** 最高司法机关条款、司法权移交

<a name="concept-constitutional-force"></a>

## 强行释宪

仅枢密院政体可强行释宪，额外花费1行动点、支持8点、稳定8点，再兑现释宪本身效果。修宪一律完成两阶段程序，不能强行颁行。

**同义词 / 可搜索词：** 强行颁行、强行修宪

<a name="concept-judge-view-0"></a>

## 社会进步

支持平等权利和进步社会议题。

<a name="concept-judge-view-1"></a>

## 政治自由

支持政治自由、独立司法与权力制衡。

<a name="concept-judge-view-2"></a>

## 墨守成规

重视既有宪法文本，对一切修宪尤其谨慎。

<a name="concept-judge-view-3"></a>

## 政治保守

反对削弱既有政治权威的修宪与释宪。

<a name="concept-judge-view-4"></a>

## 社会保守

维护传统社会秩序，反对进步社会议题。

<a name="concept-competitive-amendment"></a>

## 增加竞争性选举条文

非民主国家固定提供此修宪项。成功后：象征性民主／一党制各以50%概率转为总统制或半总统制；神权专制各以50%概率转为神权共和制或总统制；其他非民主政体各以50%概率转为君主立宪制或西敏议会制。保留历史与人物成果；按新体制重组联盟，失去入阁资格者正常离任。

**同义词 / 可搜索词：** 竞争性选举、政体转型

<a name="concept-pluralism-amendment"></a>

## 社会多元修正案

长期少数群体问题仍存在、尚未选择强制措施，且加权支持度达到80%、政治稳定达到60时可提出。两项条件恰好达到也符合；进入修宪程序后不再反复核验。须依次通过议事机关三分之二与司法半数门槛，成功即结束长期问题。

**同义词 / 可搜索词：** 社会多元、多元修宪
