# 核心指标

支持、稳定和经济指标彼此影响。下面的阈值来自当前游戏规则，不是现实政治或经济判断。数值变化应结合国家档案中的历史图表观察。

<a name="concept-approval"></a>

## 公众支持

衡量公众对政府的认可，是地区选票的基准。民生、就业、事件选择和履约会影响支持；通胀、失业、失信等会削弱支持。非民主政体中，支持每季额外影响稳定，修正为（支持−55）×0.08。

**同义词 / 可搜索词：** 支持、支持度、支持率、全国支持率、民意

<a name="concept-stability"></a>

## 政治稳定

反映社会秩序与统治基础，范围0至100。低于20会结束游戏。连续两季度低于35，且至少三个地区尚未完成地方诉求后，每季有35%概率触发叛乱，并非只要低于35就必然出现。事件和局势选项、增加行政安全预算等可提高稳定；削减行政安全预算、危机和撤换部长、总理或宰相等可能降低稳定，撤换后果还受政绩与政体影响。

**同义词 / 可搜索词：** 稳定、稳定度、国家稳定

<a name="concept-pressure"></a>

## 执政压力

每季基础支持−0.6、稳定−0.2。地方诉求进入第六季度后，未完成诉求会追加压力；债务率超过70%或赤字超过4% GDP也会增加压力。履行诉求、控制赤字与债务可减轻它。

**同义词 / 可搜索词：** 执政挑战、地方压力、财政压力、基础执政损耗
