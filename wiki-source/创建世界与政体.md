# 创建世界与政体

创建世界时可以选择政体、经济制度、世界种子、困难模式、行动点模式及管理员模式。开启新历史会替换当前进度，请先导出需要保留的存档。政体图片仅为界面示意，规则以游戏设定为准。

### 需要区分的制度规则

- 一党独大制使用**最高人民会议**，由执政党内部派别、民主党派和无党籍团体组成；前三派合计82席。
- 君主立宪制、西敏议会制开局自动组建至少50%席位的联合政府。联邦委员会制不会自动组建联盟，议案通过门槛为60%。
- 神权共和制和象征性民主制保留选举，但在本游戏中不属于48季度强制结束的民主统治规则。
- 神权共和制的宗教与行政权力安排，以及总统制另设总理，均为本游戏的简化设定。

<a name="concept-country"></a>

## 国家

这是你所扮演的虚构国家。名称只用于区分世界；政体、经济类型、地区状况和你的决策决定实际玩法。

**同义词 / 可搜索词：** 你所扮演的国家

<a name="concept-seed"></a>

## 世界种子

用于随机生成世界的输入。同版本、同种子与相同开局设置会生成可复现的世界；升级随机规则后，旧种子生成结果可能不同。

**同义词 / 可搜索词：** 种子

<a name="concept-difficulty"></a>

## 困难模式

普通模式开局随机一个局势，困难模式两个不同局势。开局池仅包含大罢工、司法公平、经济危机和政治丑闻；其他局势在执政期间触发。

**同义词 / 可搜索词：** 普通模式、开局局势

<a name="concept-economic-model"></a>

## 经济制度

经济类型决定初始产业、收入水平与增长潜力。非民主社会主义设定还决定结算时是否开放额外社会主义统治倾向。

**同义词 / 可搜索词：** 经济类型、沿海贸易国、内陆工业国、北境福利国、新兴农业国、非民主社会主义国家

<a name="concept-regime-constitutional"></a>

## 君主立宪制

你所扮演的是君主立宪制国家。君主为礼仪元首，你作为总理组阁并维持议会信任。 君主为礼仪元首；政府需维持议会信任。

<a name="concept-regime-presidential"></a>

## 民主共和制 · 总统制

你所扮演的是总统制民主共和国。总统领导政府、提出预算，与议会协商；本游戏另设总理协调内阁。 总统掌握行政授权，议会审议法案。按本游戏设定任命总理协调内阁。

**同义词 / 可搜索词：** 总统制、民主共和制

<a name="concept-regime-semi"></a>

## 半总统制

你所扮演的是半总统制国家。总统与总理分享行政职责，重大议程仍须获得议会支持。 总统与总理分享行政职责；失去议会支持会削弱施政。

<a name="concept-regime-westminster"></a>

## 西敏议会制

你所扮演的是西敏议会制国家。首相直接组阁，对议会负责，失去信任可能提前下台。 首相领导内阁，对议会多数负责；信任投票可能提前终止任期。

<a name="concept-regime-federal"></a>

## 联邦委员会制

你所扮演的是联邦委员会制国家。玩家担任协调总理，重大院内支持率须达到 60%。 各地区与委员共同治理。本游戏将玩家抽象为协调总理，重大议程需要更广泛共识。

<a name="concept-regime-theorepublic"></a>

## 神权共和制

按本游戏设定，你所扮演的是神权君主立宪体制的国家。宗教权威与民选机构并立，最高领袖领导国家。 民选机构与宗教权威并立；选举改变议会，最高领袖的存续取决于稳定。

**同义词 / 可搜索词：** 神权君主立宪体制

<a name="concept-regime-symbolic"></a>

## 象征性民主制

你所扮演的是象征性民主制国家。保留选举和议会，行政权集中；民意主要通过政治稳定影响统治。 保留选举和议会，但权力集中；支持度流失主要通过稳定危机威胁统治。

<a name="concept-regime-party"></a>

## 一党独大制

你所扮演的是一党独大制国家。最高人民会议包含执政党内部派系、民主党派和无党籍团体。 依照本游戏设定，最高人民会议代表各地区与党内路线，协商和组织支持决定政策执行。

<a name="concept-regime-absolute"></a>

## 君主专制

你所扮演的是君主专制国家。君主决定重大国务，枢密院提供政治支持，宰相负责日常治理。 宰相拥有广泛行政裁量；贵族与地方精英的配合影响王令执行。

<a name="concept-regime-aristocratic"></a>

## 贵族制

你所扮演的是贵族制国家。执政公爵需协调贵族和地方团体，宰相拥有较强行政权。 各家族分享权力，执政者必须维持枢密院中的利益平衡。

<a name="concept-regime-tyranny"></a>

## 僭主制

你所扮演的是僭主制国家。最高执政官依赖精英、地方和安全系统的配合维持统治。 统治依赖安全系统与精英效忠；低支持与低稳定会导致权力崩溃。

<a name="concept-regime-theoabsolute"></a>

## 神权专制

你所扮演的是神权专制国家。最高教长统治国家，教团组成枢密院，宰相负责行政执行。 宗教等级与行政官僚共同支撑政权，宰相负责日常统治。

<a name="concept-player"></a>

## 玩家职务

玩家职务由政体决定，统一直接控制重大政策与财政。部分政体另行任命总理或宰相，部分政体由玩家直接组阁。是否有民主选举任期限制，以政体表为准；管理员模式不受失败和回合上限限制。

<a name="concept-role-最高领袖"></a>

## 最高领袖

神权共和制中的玩家职务。最高领袖掌握重大国务决策权，没有任期；本游戏将总统和财政部长的职责一并融合于最高领袖，方便玩家游玩。

<a name="concept-role-国家主席"></a>

## 国家主席

一党独大制中的玩家职务，决定重大政策与人事，任命总理协调内阁。

<a name="concept-role-最高执政官"></a>

## 最高执政官

僭主制中的玩家职务，依赖安全系统与政治精英维持统治，任命宰相执行日常行政。

<a name="concept-role-执政公爵"></a>

## 执政公爵

贵族制中的玩家职务，需要协调枢密院内的贵族与地方利益。

<a name="concept-role-君主"></a>

## 君主

君主专制中的玩家职务，任命宰相处理日常行政；君主立宪制中君主为礼仪元首，玩家改任总理。

<a name="concept-role-最高教长"></a>

## 最高教长

神权专制中的玩家职务，领导宗教与国家事务，任命宰相协调行政。

<a name="concept-role-政府协调总理"></a>

## 政府协调总理

联邦委员会制中的玩家职务，直接安排内阁，重大议案须达到60%院内支持率。

<a name="concept-role-总统"></a>

## 总统

总统制、半总统制或象征性民主制中的玩家职务，负责重大国务并兼管财政，任命总理协调施政。

<a name="concept-role-首相"></a>

## 首相

西敏议会制中的玩家职务，直接组建内阁，对议会和选举负责。

<a name="concept-premier"></a>

## 总理

在总统制等政体中由玩家任命，协调内阁并自主执行任务；在君主立宪、西敏与联邦委员会制中由玩家直接承担相应政府首脑职责。

**同义词 / 可搜索词：** 政府首脑

<a name="concept-chancellor"></a>

## 宰相

<a name="concept-finance-minister"></a>
