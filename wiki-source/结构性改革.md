# 结构性改革

查看草案即保留它。提交、通过、执行和完成是不同阶段；窗口刷新不会删除已查看、已提交和正在执行的项目。一次性遗产税当前清偿完成时公债的50%，不再清偿全部公债。

<a name="concept-reforms"></a>

## 结构性改革

改变国家长期发展条件。先查看草案并提交议案，表决通过后启动；完成执行期后兑现效果。每六季度轮换未查看草案，已查看、已提交及正在执行的项目保留。

**同义词 / 可搜索词：** 改革、改革草案、提出改革、查看 / 提交法案

<a name="concept-reform-window"></a>

## 改革窗口

每六季度会提示旧窗口关闭并生成新草案。查看草案即保留它，启动后需等待规定季度完成；不会因为窗口刷新而丢失正在执行的项目。

**同义词 / 可搜索词：** 结构性改革窗口、改革轮换、已保留草案、执行期、执行中

## 教育与技能转型

<a name="concept-reform-inheritance"></a>

## 一次性遗产税特别征收

按本游戏特殊规则，清偿完成时 50% 的公债，支持率大幅增加；富裕贸易地区不满，增长受到持续冲击。全局限一次。 启动成本 0% GDP，执行 2 季度，长期潜在增长修正 0 个百分点；完成效果：支持 +15 · 信心 -7 · 年化增长压力 -1.6 个百分点。

**同义词 / 可搜索词：** 遗产税征收、遗产税
