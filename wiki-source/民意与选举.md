# 民意与选举

当前国家包含七个非首都地区和一个首都地区。全国支持率是地方选票的基准，并不等于全国加权选票；履约、发展、历史政策和人口权重都会改变结果。

<a name="concept-elections"></a>

## 民意与选举

全国选票由地区票率按人口权重加总。民主国家得票必须超过50%才能继续执政，选举前最后六季度会增加与历史决策有关的竞选事件。象征性民主等政体的选举主要改变稳定与席位。

**同义词 / 可搜索词：** 选举、选情、全国选举结果、单轮多数选举、单轮两方多数决

<a name="concept-forecast"></a>

## 当前加权选票预测

根据当前支持度、地方履约、历史政策与地区发展估算的票率。地区完全未履约时，基础票率最多乘80%；全国结果按地区人口权重计算。预测不等于已经完成的选举结果。

**同义词 / 可搜索词：** 预测票率、得票率、地区得票率、当前预测、加权支持、当前选情

<a name="concept-capital-region"></a>

## 首都地区

首都是独立计票地区，拥有自己的产业、社会基本盘、发展状况与地方诉求。公共服务、科研和安全相关政策可以改善首都履约；与其他地区按人口权重共同决定全国得票率。名称随政体采用特别行政区、特别市、特区、大市或领地。

**同义词 / 可搜索词：** 首都、特别行政区、大市、领地

<a name="concept-regions"></a>

## 地区

国家由七个非首都地区与一个首都地区组成，称谓随政体变化。产业、地理、社会基本盘与发展状况不同，所以相同政策对各地选票的影响也不同。具体随机地名不影响操作方式。

**同义词 / 可搜索词：** 省、特区、自治区、领、州、自治州、自治领、邦、加盟共和国、共和国（加盟）、特别市

<a name="concept-local-demands"></a>

## 地方诉求

每12季度刷新一轮，并由事件提示。符合产业或民生需要的决策、内阁任务和改革可推进诉求；已完成的要求不会重复索要。持续不履约会损害选票和稳定，灾区暂缓原有诉求惩罚。

**同义词 / 可搜索词：** 地方要求、诉求、本届诉求、本轮诉求、地区诉求、地方履约、履约进度、未满足诉求扣减

<a name="concept-development"></a>

## 发展状况

地区发展水平及其变化，影响地区对政府的认同和票率。灾害会损害发展，重建与合适政策可以改善。

**同义词 / 可搜索词：** 发展、当前发展、发展程度

<a name="concept-population"></a>

## 人口

本版人口与初始年龄结构固定，不模拟人口迁移。人口权重决定各地区在全国选举结果中占多大比例。

**同义词 / 可搜索词：** 人口权重、地区人口、65 岁以上人口、人口结构

<a name="concept-base"></a>

## 社会基本盘

地区主要居民、产业与生活背景。它们帮助你理解当地需求，政策契合度会通过履约与态度修正影响选票。

**同义词 / 可搜索词：** 基本盘、主要产业、产业结构、农业 / 工业 / 服务业、地理、宗教、历史政策修正

<a name="concept-sector-industry"></a>

## 工业

此类地区主要依靠钢铁、机械与零部件制造，社会基本盘为产业工人、工程师与工会。较关注更新工厂、保住就业；相应政策、改革和内阁任务可以推进地方诉求。

<a name="concept-sector-agriculture"></a>

## 农业

此类地区主要依靠粮食、农产品加工与乡村贸易，社会基本盘为农民、合作社与中小地主。较关注水利、农产品收入与乡村服务；相应政策、改革和内阁任务可以推进地方诉求。

<a name="concept-sector-technology"></a>

## 新型产业

此类地区主要依靠软件、生物技术与精密制造，社会基本盘为青年、科研人员与新中产。较关注科研、教育与创新投资；相应政策、改革和内阁任务可以推进地方诉求。

<a name="concept-sector-trade"></a>

## 贸易金融

此类地区主要依靠航运、金融、出口与商业，社会基本盘为企业主、白领与港口工人。较关注市场开放与稳定投资环境；相应政策、改革和内阁任务可以推进地方诉求。

<a name="concept-sector-welfare"></a>

## 公共服务

此类地区主要依靠公共服务、医疗与消费服务，社会基本盘为退休居民、公职人员与家庭。较关注医疗、社会保障与生活成本；相应政策、改革和内阁任务可以推进地方诉求。

<a name="concept-sector-green"></a>

## 生态旅游

此类地区主要依靠生态旅游、林业与清洁能源，社会基本盘为少数文化社群、旅游从业者。较关注环境保护和文化自主；相应政策、改革和内阁任务可以推进地方诉求。

<a name="concept-sector-security"></a>

## 边疆防务

此类地区主要依靠边境贸易、资源开采与军需，社会基本盘为边民、驻军家庭与传统社群。较关注治安、交通与安全保障；相应政策、改革和内阁任务可以推进地方诉求。

<a name="concept-sector-capital"></a>

## 首都行政与服务

此类地区主要依靠公共行政、商务服务、高等教育与数字服务，社会基本盘为公职人员、服务业劳动者、学生与租房家庭。较关注公共住房、城市交通与高效公共服务；相应政策、改革和内阁任务可以推进地方诉求。

<a name="concept-regional-modifiers"></a>

## 地区选票修正

地区票率以全国支持率为基准，再按未履约、超额履约、历史政策与发展状况调整。未履约最多扣20%，超额履约最多加8%；上次实际得票是已结束选举的历史结果，当前预测会随治理变化。

**同义词 / 可搜索词：** 未满足扣减、超额履约、超额履约加成、政策修正、发展修正、综合地区修正、上次实际得票、当前票率预测
