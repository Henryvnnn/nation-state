# 任期评估与统治倾向

标准时长为48季度，游戏历法每年6季度。民主国家完成两届后结算；非民主国家可在第48季度选择继续，此后每12季度再询问。提前失败也会结算。管理员模式不设任期上限，也不会因失败条件结束。

## 评估维度与候选名单

九个维度：市场取向、民生再分配、行政集权、法治制衡、国家自主、军事优先、生态优先、民粹动员、精英治理。决策记录占70%，最终政策与指标占30%。最后显示契合度最高的三项，百分比彼此独立，不相加为100%。

**民主政体候选：** 民族自由主义、宪法监护主义、威权民主主义、民粹保守主义、新保守主义、自由保守主义、古典自由主义、新自由主义、社会自由主义、社会民主主义、民粹社会主义、民主社会主义、市场社会主义、绿色社会主义、统制社会主义。

**非民主政体候选：** 君主集权派、贵族集权派、军国主义、新权威主义、贵族共和主义、威权民族主义、新国家主义、威权民主主义、民粹保守主义、温和民生派、司法自由主义、自由保守主义、社会自由主义、民粹社会主义。

**非民主社会主义国家额外候选：** 民主社会主义、市场社会主义、国家社会主义、共产主义。

<a name="concept-settlement"></a>

## 任期评估

汇总完整历史指标与三种最接近的统治倾向。仅在游戏结束后出现；进行中请在国家档案查看历史图表。民主国家第二届结束后进入任期评估，其他政体从第48季度起可以选择继续。

**同义词 / 可搜索词：** 任期结算、结算、查看任期结算、任期评估预览

<a name="concept-ideology"></a>

## 统治倾向

根据实际决策（70%）和最终政策与指标（30%）生成治理画像，与各倾向模型比较后列出前三名。契合度是相似度，不要求三项相加等于100%。

**同义词 / 可搜索词：** 契合度、统治倾向评估、治理画像、评估依据

<a name="concept-charts"></a>

## 历史折线图

国家档案实时展示经济、支持、稳定与司法等十二项指标的季度变化。点击指标卡片或图表可打开屏幕中央的大图；任期结束后评估页也保留相同图表。旧版存档未记录的数据保留空缺，不补造历史。

**同义词 / 可搜索词：** 完整任期指标、折线图、历史图表

<a name="concept-score"></a>

## 综合治理评分

根据国家经济和政治表现计算的游戏内评分，便于比较执政结果；它与统治倾向契合度分别计算。

**同义词 / 可搜索词：** 综合评分、当前综合评分
