# 部长提案图鉴

提案未完成时，每季度主管忠诚降低0.5。更换官员保留提案进度，已完成奖励不能重复领取。表内费用为基础费用，实际费用与进度以当前官员和已通过预算计算。

<a name="concept-programme"></a>

## 部长 / 大臣提案

持续的部门项目。每个项目有三个推进选项，花费、基础进度和忠诚收益不同；能力及倾向加权决定实际进度。未完成每季主管忠诚−0.5，完成后停止，换人保留进度与成果。

**同义词 / 可搜索词：** 部长提案、大臣提案、部门提案、提案进度

<a name="concept-programme-cost"></a>

## 投资如何降低费用

实际费用＝基础费用×（1−投资折扣）；各选项按相关已通过预算计算，折扣上限55%。实际进度＝基础进度×（0.75＋能力/200）×倾向系数，契合为1.25，否则为1。累计支出记录实际支付的标准货币。

**同义词 / 可搜索词：** 投资折扣、费用折扣、进度加权、基础进度、累计支出
