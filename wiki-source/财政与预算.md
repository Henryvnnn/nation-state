# 财政与预算

预算滑块只是在拟定草案。提交并经议事机关通过后才生效；经济效果会逐季传导。专项选项的“支出X% GDP”与每季度公共预算是不同的支出方式。

<a name="concept-growth"></a>

## 实际年化增长

实际经济产出的年化增长速度。教育、基础设施、改革、预算需求和投资信心都会影响增长；利率、外部环境与危机会带来压力。增长压力是持续若干季度的增长修正，不是直接发放现金。

**同义词 / 可搜索词：** GDP增长、GDP 增长、增长、增长率、经济增长、年化增长、潜在增长、增长压力、年化增长压力

<a name="concept-gdp"></a>

## GDP

国家经济总量，以十亿元标准货币计。它受实际增长与通胀影响。选项中“支出1% GDP”表示按执行时的GDP一次性增加对应金额债务。

**同义词 / 可搜索词：** 名义 GDP、名义GDP、国内生产总值、标准货币、十亿元

<a name="concept-per-capita"></a>

## 人均名义 GDP

国家名义GDP除以人口。用来观察人均经济规模，不能直接等同居民收入或实际购买力。

**同义词 / 可搜索词：** 当前人均名义 GDP、人均GDP

<a name="concept-inflation"></a>

## 通货膨胀

物价上升速度。过高通胀削弱购买力和支持，央行会调整利率回应。通胀达到50%可触发经济危机；结束危机同时要求通胀低于20%、债务/GDP低于60%。

**同义词 / 可搜索词：** 通胀、通胀率、通货膨胀率

<a name="concept-unemployment"></a>

## 失业率

劳动力中没有工作者的比例。高失业损害支持，达到10%可触发全国大罢工。救济、公共工程、民生改革和更强增长可改善就业；部分私有化或紧缩措施会短期增加失业。

**同义词 / 可搜索词：** 失业、就业

<a name="concept-debt"></a>

## 政府债务

政府尚未偿还的借款。债务/GDP衡量债务相对经济规模；赤字和专项支出增加债务，盈余和偿债措施减少债务。达到100%可触发经济危机；超过190%且信心低于25会结束游戏。

**同义词 / 可搜索词：** 债务、公债、公共债务、债务/GDP、债务 / GDP、债务率、公共债务历史、债务管理

<a name="concept-confidence"></a>

## 投资者信心

市场对国家经济、政策与偿债能力的信任。高信心有利投资和融资；高债务、赤字、政治危机和失信会使其下降。

**同义词 / 可搜索词：** 信心、投资信心、债券市场信心

<a name="concept-rate"></a>

## 政策利率

中央银行调节货币环境的基准利率。游戏中的独立央行每季度根据通胀和经济增长自动调整，玩家不能直接设定。加息通常抑制投资需求和通胀，但抬高借贷成本；降息支持经济活动，也可能增加通胀压力。政策利率还影响国债收益率与政府利息支出。

**同义词 / 可搜索词：** 利率、央行、中央银行、独立央行、基准利率、央行利率、中央银行政策利率

<a name="concept-yield"></a>

## 债券收益率

国家融资需要支付的市场利率。政策利率高、投资信心低或债务率过高，会抬高收益率与财政利息负担。

**同义词 / 可搜索词：** 国债收益率、借贷成本、融资成本

<a name="concept-rating"></a>

## 主权信用评级

对政府融资风险的游戏内分档，从AAA到CCC。主要由债务/GDP和投资者信心计算；债务高或信心低会恶化评级。

**同义词 / 可搜索词：** 评级、信用评级、AAA、AA、BBB、BB、CCC

<a name="concept-budget"></a>

## 财政与预算

调整税率和公共预算。先拟定并提交，再由权力机关表决；通过后替换现行政策。各税收和支出变化会改变不同派系的支持门槛。

**同义词 / 可搜索词：** 预算、财政、公共财政、预算草案、季度财政与公共预算案

<a name="concept-revenue"></a>

## 财政收入

收入按税基折算：个税率×0.48＋企业税率×0.19＋消费税率×0.62＋3%。提高税率可能增加收入，也会提高预算案的支持要求。

**同义词 / 可搜索词：** 收入、税收、预计财政收入、税收政策

<a name="concept-spending"></a>

## 公共支出

各项公共预算占GDP比例之和，再加固定行政支出3%。这是持续预算；事件或提案中的一次性支出另外增加公债。

**同义词 / 可搜索词：** 支出、政府支出、公共预算、预算分配、固定行政、固定行政 3%

<a name="concept-balance"></a>

## 财政余额

财政余额＝财政收入−公共支出−利息支出。正数为盈余，可偿债；负数为赤字，会增加债务。财政压力还会影响支持、稳定和信心。

**同义词 / 可搜索词：** 财政收支、财政盈余、盈余、财政赤字、赤字、预计盈余、预计赤字

<a name="concept-interest"></a>

## 利息支出

当前利息支出/GDP＝债务/GDP×债券收益率。借贷成本上升时，即使公共服务预算不变，财政压力也可能加重。

**同义词 / 可搜索词：** 债务利息、利息

<a name="concept-brake"></a>

## 债务刹车

开启后，财政赤字超过3%时每季度削减基础设施和社会保障各0.5个百分点，受最低预算限制。可改善财政纪律和信心，但也会压缩公共服务。

**同义词 / 可搜索词：** 财政规则

<a name="concept-lag"></a>

## 政策滞后

经济模型每季吸收约35%的政策变化，因此增长、就业与通胀不会立即完全响应新预算。科研、提案费用折扣和持续预算承诺按已通过的当前预算计算。

**同义词 / 可搜索词：** 经济影响逐季传导、实际执行预算

<a name="concept-policy-income"></a>

## 个人所得税

影响居民消费、收入分配与财政收入。每提高1个百分点，新预算全票支持门槛＋1，降低时相反。 可调整范围 5% 至 50%。

**同义词 / 可搜索词：** 个税、所得税

<a name="concept-policy-corporate"></a>

## 企业所得税

影响企业投资意愿与税收。每提高2个百分点，新预算全票支持门槛＋1，降低时相反。 可调整范围 5% 至 40%。

**同义词 / 可搜索词：** 企业税、公司税

<a name="concept-policy-vat"></a>

## 消费税

较稳定的税源，也会压低居民购买力。每提高1.5个百分点，新预算全票支持门槛＋1，降低时相反。 可调整范围 0% 至 30%。

**同义词 / 可搜索词：** 增值税

<a name="concept-policy-education"></a>

## 教育与科研

逐步积累人力资本，提高潜在增长。每季度科研进度增加预算数值×2；教育现代化完成后改为×3，还可降低相关提案费用。 可调整范围 1% 至 12%。

**同义词 / 可搜索词：** 教育科研、教育与科研支出

<a name="concept-policy-health"></a>

## 医疗卫生

改善公共服务，增强民众支持。公共服务改善有利民意，也可降低相关医疗提案费用。 可调整范围 2% 至 15%。

**同义词 / 可搜索词：** 卫生预算、医疗预算

<a name="concept-policy-welfare"></a>

## 社会保障

支持家庭收入，但形成长期财政义务。社会民主派尤其重视此项，预算每提高1个百分点，其全票支持门槛降低2。 可调整范围 2% 至 20%。

**同义词 / 可搜索词：** 福利、福利预算、社会保障支出

<a name="concept-policy-infrastructure"></a>

## 基础设施

短期创造需求，长期积累生产性资本。提高资本存量，支持长期生产与部分地区诉求，也降低相关建设提案费用。 可调整范围 1% 至 12%。

**同义词 / 可搜索词：** 基建、基建预算、基础设施预算

<a name="concept-policy-security"></a>

## 行政安全

维持社会秩序与行政能力。投入越高，经济模型中的稳定目标越高；削减预算可能逐步损害稳定，也会影响相关提案费用。 可调整范围 1% 至 8%。

**同义词 / 可搜索词：** 行政安全预算、安全预算

<a name="concept-capital"></a>

## 基础设施水平

反映已有交通、能源和公共设施的积累，与本季基础设施预算不同。持续投资、公共工程和改革可提高它；灾害会破坏设施。

**同义词 / 可搜索词：** 基础设施等级、基建资本、资本存量

<a name="concept-human"></a>

## 人力资本

反映知识、技能与生产能力的积累，影响潜在经济增长。教育投入、教育现代化和相关改革可以提高它；科研等级另外决定政治行动额度。

**同义词 / 可搜索词：** 教育资本

<a name="concept-budget-submit"></a>

## 提交财政方案

将预算草案送到权力机关，尚未生效。通过表决后才替换现行预算，经济随后逐季响应。

**同义词 / 可搜索词：** 提交预算、拟定预算、送交审议

<a name="concept-budget-reset"></a>

## 撤销未提交调整

把尚未提交的预算滑块恢复为现行政策，不改变已经提交的议案或生效政策。

**同义词 / 可搜索词：** 撤销调整

<a name="concept-sports"></a>

## 体育基础

体育设施与组织能力，范围0至10。相关改革和事件可提高它，从而增加尚未使用奥运机会时收到申办邀请的概率。

**同义词 / 可搜索词：** 国家体育、体育事业

<a name="concept-culture"></a>

## 文化基础

公共文化设施与文化事业的积累。文化投入和改革能改善民生与就业，并影响地区需求和历史评估。

**同义词 / 可搜索词：** 国家文化、文化事业
