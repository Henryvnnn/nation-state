# 议事机关与联合政府

先准备预算或改革，再协商支持，最后提交表决。院内支持率是确定的加权结果，不是通过概率；“议程倾向”“团体关系”“院内支持率”是三个不同概念。

## 表决计算示例

全票支持门槛以60为基准。相对现行预算，个税每变化1个百分点使门槛同向变化1；消费税每变化1.5个百分点对应1；企业税每变化2个百分点对应1。公共支出再按各党偏好修正，执政党也适用。

- 折算倾向 = 议程倾向 −（本案全票门槛 − 60）。
- 党团支持比例 = 将（折算倾向 − 50）÷10限制在0—1范围内。
- 院内支持率 = 各党席位 × 各党支持比例的总和 ÷ 总席位 ×100%。

例如一个30席党团的折算倾向为55，其支持比例为50%，计入15个支持权重。一般政体总院内支持率达到51%通过，联邦委员会制达到60%通过。低于50的各派系折算倾向还会在议案通过后产生稳定损失。

<a name="concept-assembly"></a>

## 权力机关

审议预算和改革的机关。民主及部分共和政体使用议会，一党独大制使用最高人民会议，专制和贵族政体使用枢密院。可协商党派、会见负责人、提出并表决议案。

**同义词 / 可搜索词：** 议会、立法机关、枢密院、最高人民会议、人民会议

<a name="concept-groups"></a>

## 政党与派系

政党和派系代表不同政治力量。席位决定其表决权重，团体关系、成员关系、倾向和政策偏好决定支持。一党独大制中的前三组是执政党内部派系，并非三个竞争执政党。

**同义词 / 可搜索词：** 政党、党派、派系、党团、政治团体、执政党、执政派系、民主党派、无党籍团体、主流派、新锐派、改革派

<a name="concept-seats"></a>

## 席位

决定各党或派系在立法机关的表决权重。它与支持比例共同计算总院内支持率；枢密院使用同样机制表示政治配合程度。

**同义词 / 可搜索词：** 议席、席、议席比例、议事权重、权力构成

<a name="concept-faction-relation"></a>

## 团体关系

政府与一个党派或派系的关系，范围0至100。协商、任命、事件和承诺会影响它。民主与象征性民主政体中，关系达到70后，可向该党总召邀请组建联合政府。

**同义词 / 可搜索词：** 派系关系、党派关系、集团关系

<a name="concept-member-relation"></a>

## 个人关系

政府与立法机关具体成员的关系。会见回应可改变它，并通过该派系主要成员的平均关系影响议程倾向。

**同义词 / 可搜索词：** 成员关系、关系

<a name="concept-agenda"></a>

## 议程倾向

当前政治力量对政府议程的支持程度，由团体关系、成员关系、议案取向和临时承诺共同决定。非玩家派系每季减少2点，玩家派系豁免；成功协商可抵消最多8点累计季度损耗。

**同义词 / 可搜索词：** 议席倾向、支持倾向

<a name="concept-faction-profile"></a>

## 派系路线

概括党派的政治偏好和最关注的公共预算。增加其偏好的投入会降低该党全票支持门槛，削减时相反；详细系数可在“查看细则”中展开。人物倾向与所属派系路线关联。

**同义词 / 可搜索词：** 关注重点、预算偏好、保守建制、自由市场、社会民主与民生、地方自治与基层服务、绿色与公共教育、法治与公民权利、国家统制、改革与技术治理、传统宗教与秩序

<a name="concept-full-support"></a>

## 全票支持门槛

基准60。相对现行预算，税率变化会提高或降低门槛，公共支出按各派系偏好另行修正，执政党也适用。议程倾向达到该门槛时，该派系全体议席支持。

**同义词 / 可搜索词：** 预算门槛、支持门槛

<a name="concept-effective-agenda"></a>

## 折算倾向

折算倾向＝议程倾向−（本案全票支持门槛−60）。50对应0%支持、51对应10%、60对应100%，中间按比例计算。

<a name="concept-faction-support"></a>

## 党团支持比例

该派系支持议案的议席比例，范围0%至100%。将各派系的支持比例按席位加权，即得到院内支持率。

**同义词 / 可搜索词：** 支持比例、支持席位权重

<a name="concept-pass-rate"></a>

## 院内支持率

按各党席位加权的总体支持百分比。一般预算／改革达到51%即通过，联邦委员会制需60%；释宪须严格超过50%；修宪须先取得三分之二院内支持，司法审查达到半数即可。达到相应门槛必定通过。低折算倾向派系另产生通过后的稳定损失，不是一次随机抽签。

**同义词 / 可搜索词：** 通过率、议案通过率、议会通过率、表决支持率、通过门槛、政府议程支持、当前基础院内支持率、所需院内支持率

<a name="concept-opposition-cost"></a>

## 反对压力

各派系折算倾向低于50的每一点，在议案通过后扣除0.1稳定度，多个派系累加。原有通过收益另计；表决失败不额外扣这部分损失。

**同义词 / 可搜索词：** 额外稳定损失、稳定损失

<a name="concept-negotiate"></a>

## 协商

打开该党派或派系的谈判选项，以资源、监督或承诺争取支持。执行选项通常消耗1点行动点；查看窗口不消耗。临时支持有期限，承诺会接受核查。

**同义词 / 可搜索词：** 派系协商

<a name="concept-faction-details"></a>

## 查看细则

展开或收起门槛、折算倾向、席位权重及公共预算偏好。不消耗行动点，也不改变政策。

**同义词 / 可搜索词：** 细则、查看表决计算规则

<a name="concept-meet"></a>

## 会见 / 回应诉求

与议长、秘书长及党团代表等交流。每人每季度一次，执行回应消耗1点行动点；回应影响关系、政策与最终统治倾向。

**同义词 / 可搜索词：** 会见、回应诉求、主要成员

<a name="concept-bill"></a>

## 政府议程

当前送交权力机关的预算或改革。一次只能审议一项，表决通过后才实施；失败保留提案，可继续协商或撤回。

**同义词 / 可搜索词：** 议案、法案、待表决、提案表决

<a name="concept-vote"></a>

## 提交表决

消耗1点行动点，按当前院内支持率决定议案是否实施。失败会损失支持与稳定；议会制连续三次失败且支持低于45时，可能通过不信任案结束游戏。

**同义词 / 可搜索词：** 投票、表决

<a name="concept-withdraw"></a>

## 撤回

取消当前待决议案，不改变已经实施的政策。之后可重新拟定预算或提出其他改革。

**同义词 / 可搜索词：** 撤回议案

<a name="concept-promise"></a>

## 协商承诺

有期限的政治约定。按时完成会改善关系与支持；失信产生惩罚并进入竞选与结算记录。临时议程支持是暂时加成，重复同类协商只延长期限。

**同义词 / 可搜索词：** 承诺、临时支持、已兑现、履约、失信、未兑现承诺、协商承诺追踪

<a name="concept-coalition"></a>

## 联合政府

民主与象征性民主政体中，只有执政联盟所属人物可任命为阁员。君主立宪制和西敏议会制开局组成至少占50%席位的联合政府，其他支持组阁的政体开局为单党政府。其他党团关系达到70后，可会见其总召并消耗1行动点邀请加入。其余非民主政体允许所有派系入阁，不设联合政府邀请选项。

**同义词 / 可搜索词：** 组阁资格、执政联盟、邀请组建联合政府

<a name="concept-political-ally"></a>

## 政治盟友

君主立宪制和西敏议会制的开局与政策偏好最接近的党派结盟，再补充其他党派直到联盟拥有至少50%席位。盟友初始议程倾向为60，团体关系随机60至70，人物可入阁；其他民主与象征性民主开局为单党政府。盟友关系低于50触发政府危机。

**同义词 / 可搜索词：** 盟友、联合政府信任

<a name="concept-party-colors"></a>

## 政党颜色

座席、党派名称与人物标识使用一致的政治路线配色：社会民主／劳动派为梅红，自由民主／自由市场派为黄色，国民／保守派为蓝色，绿色派为绿色，法治自由派为浅蓝，国家统制派为红色，地方自治派为青绿，技术改革派为紫色，传统宗教派为赭金。颜色由名称与政治路线决定，不由列表顺序决定。

**同义词 / 可搜索词：** 党派颜色、议会颜色、席位颜色
