# 快速入门

第一次游玩建议选择普通模式和固定行动点，先熟悉一季的决策顺序。

1. **创建国家。** 选择政体卡片；下方缩略图铺满边框，选中后上方显示完整图片与身份、议事机关、行政机构。
2. **查看风险。** 在总览检查支持、稳定、就业、债务和局势，先处理近期会造成失败的风险。
3. **安排人事。** 补齐内阁空缺，查看忠诚、能力、本季任务与未完成提案。
4. **处理议程。** 拟定预算或改革，查看院内支持率；不足时先协商，再花费行动点表决。
5. **回应地方。** 留意尚未完成的地方诉求、盟友关系与加权选票预测。
6. **推进季度。** 结算经济、科研、官员任务及局势，回复至少三件季度事件，再处理选举或任期结算。
7. **复盘。** 点击指标查看折线图，或进入国家档案观察长期趋势。

| 事项 | 时间或门槛 |
| --- | --- |
| 游戏历法 | 每年6季度，每届24季度 |
| 民主选举 | 第24、48季度；加权得票须超过50% |
| 民主任期上限 | 两届，48季度 |
| 非民主继续执政 | 第48季度询问，此后每12季度再询问 |
| 改革窗口 | 每6季度刷新未查看草案 |
| 地方诉求 | 每12季度换一轮 |
| 普通游戏的稳定失败线 | 稳定低于20 |

## 推进季度

推进一季度会结算经济、官员施政、科研和持续局势，并恢复行动点。每季度至少三件决策事件，回复完成后才进行选举和任期结算。

**同义词 / 可搜索词：** 下一回合、推进回合、回复季度事件、本季已回复事件、待决事件

<a name="concept-calendar"></a>

## 季度

本游戏每年有 6 季度，每届 24 季度。民主国家在第24、48季度选举，完成两届后结算；其他国家第48季度可继续，此后每12季度再次询问。

**同义词 / 可搜索词：** 回合、年份、年、任期、本届已过、距选举 / 评议
