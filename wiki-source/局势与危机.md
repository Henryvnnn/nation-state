# 局势与危机

普通开局抽取一个局势，困难模式抽取两个不同局势。开局池只有大罢工、司法公平、经济危机和政治丑闻；奥运、灾害、叛乱、民主化运动及政府危机在执政中出现。局势持续影响可以相互叠加。

<a name="concept-situations"></a>

## 局势

跨多个季度持续的国家挑战或大型项目。局势页列出触发背景、结束条件、季度影响、专项成本及处置按钮；结束后会有结果通知与历史记录。

**同义词 / 可搜索词：** 国家局势、持续危机、局势档案、结束条件、每季影响

<a name="concept-cooldown"></a>

## 冷却

行动暂时不能再次使用的期限，通常随季度推进解除。“限一次”指该局势内只能用一次；奥运申办则整局仅一次。大罢工紧急救济无季度冷却，但仍消耗资金和行动点。

**同义词 / 可搜索词：** 冷却季度、冷却时间、限一次

<a name="concept-strike"></a>

## 全国大罢工

失业达到10%可出现，开局抽中时失业为15%。每季损害增长与信心，并使支持和稳定各−2；失业降到5%以下结束。可持续满足福利或教育预算承诺，也可使用救济与四季度公共工程。

**同义词 / 可搜索词：** 大罢工、罢工

<a name="concept-justice-situation"></a>

## 司法公平事件

司法独立降至20可出现，开局抽中时独立性为10。每季支持、稳定各−2，并损害信心与增长；独立性超过40结束。非民主和象征性民主政体还有永久禁止此类抗议的选项，但不消除其他政治风险。

**同义词 / 可搜索词：** 司法公平、司法抗议、民权运动

<a name="concept-economy-situation"></a>

## 经济危机

通胀达到50%或债务/GDP达到100%可出现。每季失业+1，支持、稳定各−2，并损害增长与信心。需同时将债务/GDP降到60%以下、通胀降到20%以下才能结束。

**同义词 / 可搜索词：** 危机

<a name="concept-scandal"></a>

## 政治丑闻

采购和利益输送等争议形成的持续局势。调查进度达到100%且完成责任处理后结束；未解决时损害支持、稳定、信心及涉事派系的议程倾向。

**同义词 / 可搜索词：** 丑闻、调查进度、责任处理、责任认定

<a name="concept-olympics"></a>

## 奥运

本局最多成功申办一次；接受申办即使用机会，取消或失败不退还。第12季度后，在稳定至少60、无叛乱和灾害等条件下可能收到邀请，体育基础越高越容易出现。拒绝不消耗机会。接受成本0.3% GDP，筹备八季度，每季维护0.15% GDP。届时进度完成100%、质量达到40即成功：支持+6、信心+3，未来六季增长压力+0.5；超支超过40时支持收益改为+3，另增2% GDP债务。失败为支持−8、信心−4、稳定−3，超支代价仍在；举办后可处理场馆。

**同义词 / 可搜索词：** 奥运会、奥运申办、奥运筹办、奥运筹备、主办奥运、奥运申办邀请、场馆处置

<a name="concept-olympic-quality"></a>

## 奥运质量

筹备进度表示设施和组织的完成度；质量决定能否合格举办；超支是风险指数，不是GDP比例。结算时进度完成100%、质量达到40可成功；超支超过40会追加2% GDP债务并减少支持收益。

**同义词 / 可搜索词：** 质量、超支、筹备进度

<a name="concept-disaster"></a>

## 重大自然灾害

执政期间可能发生，不进入开局局势池。灾害损害生产、设施与地区发展；需将救援、安置、重建全部完成到100%才结束。救援与安置先完成后，最严重的季度损耗停止，仍需重建。

**同义词 / 可搜索词：** 自然灾害、灾害、洪灾、地震、农业旱灾、沿海风暴、森林大火、山地滑坡、救援、安置、重建、严重度

<a name="concept-rebellion"></a>

## 叛乱

稳定连续两季低于35、至少三个地区未履约后，每季35%概率出现。结束需强度低于20、社会基础低于30、控制力超过60；若通过谈判结束，还需按时兑现地方和平承诺。控制力低于10或军队忠诚低于20会导致游戏结束。

**同义词 / 可搜索词：** 叛乱局势、强度、社会基础、控制力、军队忠诚、谈判、和平协议

<a name="concept-spring"></a>

## 民主化运动

非民主政体在独立性低、支持不足和经济危机等条件下积累民主化压力，执政中可能出现。可通过可信改革、制宪转型或压制处理；压制会保留未解决的压力。转型保留已执政季度、历史与经济进度，并举行竞争性选举。

**同义词 / 可搜索词：** 之春、民主化运动局势、民主转型、改革可信度、激进度、运动规模、统治集团团结、军警忠诚

<a name="concept-qe"></a>

## 量化宽松应急安排

本游戏的特殊危机机制：暂移现有公债5%，同时增加通胀等代价。经济危机结束或任期结算时必须全部计回，因此不等于永久偿债。

**同义词 / 可搜索词：** 量化宽松、应急债务回表、债务回表、待回表债务

<a name="concept-government"></a>

## 政府危机

任一政治盟友关系低于50时出现，持续期间每季支持率−1、政治稳定−3。必须在三季度内把失信盟友关系恢复到60以上，或按关系达到70的邀请规则争取新党派，组成至少50%席位的新联盟。本局势无独立选项，只能在议事机关协商；另组新联盟会让原盟友所属阁员全部辞职，并逐人承担强制辞职后果。君主立宪与西敏政体逾期直接倒阁；其他支持联合政府的政体逾期解散联盟、盟友阁员离任，不直接结束游戏。

**同义词 / 可搜索词：** 联合政府危机、政府不信任案
