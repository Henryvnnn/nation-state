# 界面教程与存档

入门教程只讲总体目标，具体概念由各页右上角“本页教程”介绍。两种教程都能按空格进入下一步、Esc退出；不会消耗行动点或改变预算草案。

<a name="concept-overview"></a>

## 执政总览

查看国家主要指标、当前局势、待决事件与执政压力，是统筹本季工作的入口。

**同义词 / 可搜索词：** 国家总览、总览

<a name="concept-archive"></a>

## 国家档案

查看科研、行动额度、国家结构、债务历史和执政记录，并导入或导出存档。

**同义词 / 可搜索词：** 档案、国家基本档案、执政纪事

<a name="concept-save"></a>

## 本地自动存档

游戏进度保存在当前浏览器的本地存储中。换浏览器、换设备或清除站点数据后不会自动同步，建议用导出存档备份。

**同义词 / 可搜索词：** 存档、自动存档

<a name="concept-export"></a>

## 导出存档

下载当前进度的JSON文件，可用来备份或在另一设备恢复。

**同义词 / 可搜索词：** 导出

<a name="concept-import"></a>

## 导入存档

选择此前导出的存档文件，验证成功后替换当前进度；旧版存档会按规则迁移。

**同义词 / 可搜索词：** 导入

<a name="concept-new-world"></a>

## 开启新历史

重新生成国家并替换当前进度，可设置世界种子、政体、经济制度与困难模式。保留旧进度请先导出存档。

**同义词 / 可搜索词：** 新世界、重新开始、新世界自定义

<a name="concept-guide"></a>

## 治国指南

输入游戏里的概念或同义词，查看统一条目的解释。搜索不改变进度、不消耗行动点；不收录普通事件标题和随机人物、政党或国家名字。

**同义词 / 可搜索词：** 指南、概念搜索、搜索

<a name="concept-tutorial"></a>

## 入门教程

左栏的入门教程简要介绍政体称呼、受托机构、任期、执政目标、9维评估、治国指南和本页教程的使用方法。不会自动讲解所有板块；可按空格进入下一步，或用左右方向键浏览，右下角跳过或Esc退出。

**同义词 / 可搜索词：** 教程、开启教程、新手教程、跳过教程

<a name="concept-page-tutorial"></a>

## 本页教程

先在左栏选择需要了解的板块，再点击主窗口右上方“本页教程”。按空格进入下一步。只高亮和讲解当前板块中的概念与功能按钮，不跳转到其他板块，不执行政策或消耗行动点。

**同义词 / 可搜索词：** 页面教程、板块教程

<a name="concept-alerts"></a>

## 执政提醒

问题出现时首次弹出提醒，红点持续到问题解决。点击“知道了”会将提醒收至页面边缘，可点击侧边按钮重新展开，也可上下拖动按钮调整位置。收起提醒不会清除红点；提醒不会加入待决事件，不阻碍季度推进。包括空缺、忠诚低于35、未解决局势、选票或支持低于50%、稳定低于35、失业超过8%、通胀超过45%、债务率超过90%、司法独立低于30，以及下季度将刷新未查看改革草案。

**同义词 / 可搜索词：** 红点、提示、风险提示、提醒

<a name="concept-console"></a>

## 控制台

仅在创建新世界时选择管理员模式后开放，按钮位于左侧导航最下方。可直接调整经济、政治、预算、地区、人物、科研与局势数据，生成事件或测试内阁空缺；保留正常模拟，但取消所有失败结局和回合上限。只有开启新历史才能替换本局。此模式与存档一起保存，普通存档不会自动开启。

**同义词 / 可搜索词：** 管理员模式、管理员模式（不建议）
