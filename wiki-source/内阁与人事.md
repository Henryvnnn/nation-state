# 内阁与人事

先看候选人的党派、能力、忠诚和倾向，再决定任命。部长季度任务与持续提案并行：任务在推进季度时自主执行，提案由玩家投入行动点推进。

<a name="concept-cabinet"></a>

## 内阁与人事

任命、撤换官员并安排施政任务。官员按能力、倾向和忠诚自主执行，季度报告呈现结果；财政部长由玩家兼任。

**同义词 / 可搜索词：** 内阁、阁员、内阁席位

<a name="concept-skill"></a>

## 能力

官员处理任务的水平。能力越高，自主任务成功率与部长提案进度加权通常越高；提案能力系数＝0.75＋能力/200。

**同义词 / 可搜索词：** 能力值

<a name="concept-loyalty"></a>

## 忠诚

官员对政府的合作意愿，影响自主执行效果。部门提案未完成时每季降低0.5；推进提案选项可增加1至3点。某些事件会大幅改变忠诚，事件后低于30的在任官员可能主动辞职。

**同义词 / 可搜索词：** 忠诚度

<a name="concept-achievements"></a>

## 累计政绩

官员已取得的施政成果。自主任务和完成提案可增加政绩；罢免政绩较高的官员通常引发更明显的政治后果。

**同义词 / 可搜索词：** 政绩、历史政绩

<a name="concept-tenure"></a>

## 任职

当前官员在该职位已任职的季度数，随季度推进增加。重新任命会重新计算其任职时长。

**同义词 / 可搜索词：** 任职季度

<a name="concept-traits"></a>

## 政治倾向

人物的施政偏好，会影响自主任务、司法独立和提案执行。人物倾向与党派关联；与提案契合时，提案进度另乘1.25，否则乘1。它与议程倾向、结算统治倾向属于不同指标。

**同义词 / 可搜索词：** 倾向、倾向契合、倾向契合度

<a name="concept-task"></a>

## 本季任务方向

为官员指定持续的施政重点，不消耗行动点；左侧席位卡显示当前安排，下次推进季度执行。政府首脑与副职保留综合任务，其他部长各有五种职责相关方向。自主判断按政治倾向选择部门任务；能力、忠诚和执行结果决定实际效果，季度报告会列出。

**同义词 / 可搜索词：** 任务、任务指令、任务方向

<a name="concept-reports"></a>

## 季度施政报告

记录各官员的自主任务结果及提案完成情况，可用于判断留任或撤换。

**同义词 / 可搜索词：** 季度报告、施政报告

<a name="concept-appoint"></a>

## 任命

在符合组阁资格、尚未任职的人物中选择官员，确认消耗1点行动点。同一人物不能同时占据多个内阁职位；任命政府首脑或司法主管还会影响司法独立。

**同义词 / 可搜索词：** 候选人名册、候选人、任命确认

<a name="concept-replace"></a>

## 重新任命

打开合资格候选人名册，确认前会展示旧任离职后果。部门提案进度与已经完成的成果保留，不会因换人重复发奖。

**同义词 / 可搜索词：** 重新任命部长、重新任命大臣

<a name="concept-dismiss"></a>

## 要求辞职

让现任官员离职，消耗1点行动点。政治后果取决于政绩、职权和政体；总理、尤其宰相离职的冲击更大。职位空缺期间也会持续损失稳定。

**同义词 / 可搜索词：** 辞职、罢免、开除部长、开除大臣、开除总理、开除宰相、撤换官员

<a name="concept-vacancy"></a>

## 职位空缺

政府首脑空缺每季损失3稳定；其他部门每席每季损失0.25稳定。空缺部门无法推进提案，应从合资格候选人中补任。

**同义词 / 可搜索词：** 空缺

<a name="concept-trait-务实协调派"></a>

## 务实协调派

重视谈判与跨派系合作，优先稳定政府；行政效率较为平衡。

<a name="concept-trait-法治改革派"></a>

## 法治改革派

保护司法独立，愿意接受监督；改革会触动既得利益。

<a name="concept-trait-财政技术派"></a>

## 财政技术派

优先清理低效支出、提高投资信心，但削支可能得罪选民。

<a name="concept-trait-民生扩张派"></a>

## 民生扩张派

倾向增加公共服务与临时补助，支持度回升但债务增加。

<a name="concept-trait-强硬集权派"></a>

## 强硬集权派

强调行政命令与秩序，短期提高稳定，却侵蚀司法独立。

<a name="concept-trait-社会民主派"></a>

## 社会民主派

主张累进税、劳动保障和普惠公共服务，在市场经济中推动再分配。

<a name="concept-trait-国家统制派"></a>

## 国家统制派

强调国家主导战略产业、投资与资源配置，偏好集中协调和行政动员。

<a name="concept-trait-市场社会派"></a>

## 市场社会派

以公共所有、合作社与市场竞争结合，兼顾就业保障和企业效率。

<a name="concept-trait-自由贸易派"></a>

## 自由贸易派

主张开放贸易、私营投资与较低税负，愿意以短期就业调整换取增长。
