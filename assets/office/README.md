# 办公室美术

这些插画来自本项目确认的办公室界面预览。保留清晰轮廓、适度细节和少量明暗，图片已压缩为 WebP；不包含游戏中的数据或按钮。

| 文件 | 用途 |
| --- | --- |
| `republic.webp` | 开始页；总统制、半总统制、联邦委员会制、象征性民主和僭主制办公室 |
| `palace.webp` | 君主立宪制、西敏议会制、君主专制和贵族制办公室 |
| `party.webp` | 一党独大制办公室 |
| `theocratic.webp` | 神权共和制和神权专制办公室 |
| `map.webp` | 地区目录的背景示意图；编号、地区名称、诉求与选举预测来自实际存档 |

物品轮廓位置由 `office.js` 的 `hitShapes` 定义。文件与钢笔、电话与线缆分别组成一个交互物品；整组轮廓一起发光。替换办公室插画时应同时校对这些轮廓。小屏使用桌面下方的文字入口，所有功能保留。
