## 1.0.1 更新

- 修正党派身份：每党只有一位党团总召或首席代表；四位议事机关负责人独立保留。
- 九种人物倾向、常规随机党名、七个按政体命名的随机地区；展示地区产业、地理、宗教、基本盘与发展。
- 地区票率由全国支持率、履约、发展与历史政策共同决定；按人口权重进行单轮两方多数决。
- 游戏历法为每年六季度、每届二十四季度。民主国家最多四十八季度；非民主国家四十八季度后可继续，每十二季度再次询问。
- 结算显示十二项完整历史图表，按决策（70%）与政策/指标（30%）生成九维画像，展示前三项倾向及契合度。非民主社会主义扩展列表由开局经济制度决定。
- 改革每六季度刷新未查看草案，保留已查看、已提交与执行中的项目。十九类改革包含国有化、私有化、一次性遗产税清债、主权基金、体育及文化投入。
- 每季度至少三个决策事件，涵盖经济、议会、地区、部长、司法、竞选、国际、安全、灾害、文化与体育。
- 自动迁移旧存档并在本机保留升级前备份；旧历史未记录的指标显示缺口，不补造数据。

注：这是简化的游戏模型。倾向契合度是游戏内部相似度，不是现实政治鉴定。

## 1.0.2 更新

- 新世界新增困难模式：普通开局随机一个局势，困难开局两个不同局势，按政体加权；同种子同模式可复现。奥运、灾害、叛乱和民主化运动不会进入开局池。
- 新增局势页面：全国大罢工、司法公平事件、经济危机、政治丑闻、奥运筹办、重大自然灾害、叛乱、以国家简称命名的民主化运动。
- 局势具有持续效果、结束门槛、行动点成本、冷却、处置记录与结束事件；包含连续四季度预算承诺、工程延迟兑现、债务回表、救灾重建、调查问责、赛后场馆处置与民主转型选举。
- 一党独大制改为执政党主流派35席、新锐派22席、改革派25席、民主党派16席、无党籍团体2席；其他政体采用各自名称池，神权与世俗枢密院不再采用普通政党名称。
- 地方诉求每12季度轮换。当前已完成诉求不再重复出现，已排队事件同样检查；保存历史履约，灾区暂停原诉求惩罚。
- 每季基础支持损耗0.6、稳定损耗0.2，地方失信与财政压力追加损耗。危机叠加构成主要难度；移除试验版本的固定6点民意重罚。
- 旧存档升级保留历史与进度，不追加开局局势；重新载入不会重复抽取。内部存档schema保持兼容，显示版本统一为1.1.2。

加载顺序：`game.js` → `political.js` → `governance.js` → `revision12.js` → `situations.js` → `release103.js` → `release104.js` → `cabinet-tasks.js` → `release107.js` → `coalition107.js` → `interface107.js` → `console107.js` → `guide.js`；最后启动。`revision12.js` 文件名来自开发阶段，已包含于1.1.2正式版本。

## 1.0.3 更新

- 大罢工紧急救济金取消季度冷却，可在同季反复使用，每次仍消耗 1 行动点与 2% GDP；公共工程改为四季度冷却和交付。前两项连续预算承诺保持原规则。
- 内阁十类职位各有持续提案、三个推进选项、投资折扣、能力与倾向加权。未完成每季主管忠诚 −1，选项忠诚 +1～3；换人保留进度，完成奖励不可重复领取。
- 教育现代化：师范设施基础费用 1.05% GDP/进度32，城市设施0.75%/24，乡村机构0.45%/16。实际进度 = 基础进度 ×（0.75 + 能力/200）× 契合加成（1或1.25）。费用按已通过预算折扣，最多优惠55%。
- 科研进度每季增加教育预算数值×2，教育现代化完成后×3。每100进度升一级，保留余数；每级增加1点季度政治行动额度，初始3点、最多6点。国家档案显示科研与额度。
- 议程倾向每季下降2点，玩家派系豁免；协商可抵消最多8点已积累损耗。预算全票门槛以60为基准：个税变化/1 + 消费税变化/1.5 + 企业税变化/2，再减各派系的公共投入偏好；执政党同样适用。
- 比例席位：折算倾向 = 原倾向 −（预算全票门槛−60）；50对应0%，51对应10%，60对应100%。席位保留小数权重；每个低于50的倾向点只在议案通过后扣除0.1稳定，另外保留原有通过收益。
- 民主与象征性民主政体只允许执政联盟人物入阁。其他党团关系达到70后，向该党总召发出联合政府邀请（1行动点）；非民主的其他政体保留全派系任命。每个派系12名候选人，人物倾向与派系路线关联。
- 可见比较符号改为“＞/＜”，相应局势结束门槛使用严格比较；前两项罢工预算承诺以“至少”表述并保持原机制，计时到期、100%完成与70关系组阁不改变。
- 自动兼容旧存档，不追溯科研；升级前副本保存在本地存储 nation-state-v1-pre-103。不合组阁规则的旧任命免费调整，保留历史、资金及已付费工程交付日期。

文字调整：新提案名称、选项、派系路线和说明集中在 `release103.js`；局势文案在 `situations.js`。改完提交到 main 后，Pages 自动重新发布。

- 内阁左侧每个在任官员显示“本季任务”。更改任务立即更新状态，不消耗行动点，下一季度执行；指令持续至再次更改。
- 政府首脑及副职保留原九种任务与执行效果。外交、国防、司法、内政、教育、卫生、文化、环境八部门各有五种方向：自主判断、改善本部门财政、三种职责专属任务。自主判断依官员倾向选择部门路线；其他方向有不同的财政、民意、稳定、经济或司法后果。

- 旧部长任务自动映射到最相近的新方向，保留人物、政府首脑/副职任务和部门提案进度；升级前备份为 `nation-state-v1-pre-105`。

- 提案、改革、事件生成说明、季度报告与任务面板共用同一效果格式化函数，每个实际指标只输出一次，保持百分比及百分点单位；去除多余小数零，并保留小额财政费用。
- “普惠医疗网络”今后完成时降低失业率0.5个百分点，说明与实际结算同步。已经完成的旧项目保留原有收益与历史说明；新完成项目记录实际奖励，防止重复领取。

## 1.0.6 更新

- 一党独大制的议事机关统一改为“最高人民会议”，同步更新导航、说明、教程、指南与旧存档的文字引用。

- 简报按政体使用政务院、首相府、总统行政办公室等名称；总览简报过滤版本更新通知，旧存档立即生效，原始历史保留在国家档案。
- 执政提醒点击“知道了”后收起至可上下拖动的侧边按钮，点击可再次展开；位置和收起状态会保存。未解决风险仍保留红点，提醒数值实时更新，新问题首次出现时展开。
- 入门与本页教程支持空格进入下一步，长按不会连跳；按钮改为“空格进入下一步”，末步显示“空格完成教程”，继续支持左右键、鼠标和Esc。
- 创建世界改用十二种政体的插图卡片及随机选项，展示玩家身份、制度特点和行政机构，选中后可预览。图片使用玩家指定的十二张原图，卡片缩略图等比例裁切铺满边框，点击后在上方显示完整图片；西敏议会制更换为玩家新提供的横向图片。

- 创建世界新增固定、随机、伪随机三种行动点模式，旧档继续采用固定模式且保留剩余点数。固定模式每季3点，科研每级加1、上限6；随机模式每季投骰，科研每级将下限提高1，最高变为6—6；伪随机模式开局预排第1—48季度，1—6各出现8次并打乱顺序，每级科研叠加1点且允许超过6点。开局另发初始额度，超过48季度按种子续排。所有模式未用完不结转，同季刷新、导入和重复读取不重投。
- 教程拆分为左栏七步“入门教程”与右上方“本页教程”。入门只讲政体欢迎、受托机构、任期、目标、9维评估、治国指南与分板块学习方法；本页教程只介绍所选页面。行动点与科研说明随模式变化，继续支持高亮、键盘、跳过和返回原页面。

- 一次性遗产税特别征收改为清偿完成时现存公债的50%；GDP不变时，债务/GDP为70%会降至35%。仍全局限一次，不追溯重算已完成的改革。
- 新增劳动部长/大臣，包含任命、季度任务、报告、辞职与更换。五种任务为自主判断、改善本部门财政、就业促进、劳动权益保障、劳资协商；部门提案“就业与劳动保障计划”有三项措施，受能力、倾向和公共投资加权，完成后失业率−0.7个百分点、支持率＋3、稳定度＋2。
- 补充政策利率说明、基准利率等搜索别名，在政策利率图表标题旁提供解释按钮。概念搜索忽略首尾标点，输入“政策利率、”也能找到条目。
- 民意与选举扩为七个非首都地区及一个独立首都地区。首都占12%人口权重，拥有自己的发展、履约、地方代表和选票，也可能遭遇城市洪涝。首都称谓随政体使用特别行政区、特别市、特区、大市或领地。
- 地名使用大量音节组合或地理词组合，局内唯一、同种子可复现。非首都地区增加邦、加盟共和国、特别市、特区等称谓；联邦地区可出现邦与加盟共和国，王室及枢密院政体使用领、自治领等。
- 权力构成改为与各派席位数量及颜色对应的100个座席。一般议会与最高人民会议为半圆图，西敏议会制和枢密院为两侧对坐图；图内没有文字，党派说明与协商按钮保留在下方。
- 民主国家新世界从席位严格超过25的党派中随机选取玩家党派，允许小于最大党；组阁、联合政府、季度倾向损耗和选后议席归属均使用实际玩家党籍，并显示“玩家所属”标记。已有存档不重新抽取党籍。
- 旧存档保留内阁身份、能力、任务、提案进度、地方履约和历史票数，免费补充劳动部长与首都。首都继承原全国加权履约水平，避免新增地区立刻惩罚旧进度；过去的投票不补造首都结果。升级前备份为 `nation-state-v1-pre-107`，刷新不重复迁移。

- 指标卡片支持鼠标点击与键盘打开居中的历史图表弹窗。国家档案新增与最终评估相同的十二项完整任期指标，按现有季度记录同步更新；第一条记录也显示数据点，旧存档缺失值不补造。任期评估仅在游戏结束后出现在导航中，进行中的图表查看转到国家档案。
- 治国指南移到开启教程下方，使用同等大小的明显按钮；教程同步介绍新的档案图表与提醒规则。

## 1.0.7 · 宪法、最高司法机关与长期局势

- 议会权力构成图改为政治路线配色，党派卡片、座席与人物标识同步：社会民主／劳动派用梅红，自由民主／市场派用黄色，国民／保守派用蓝色；绿色、地方自治、法治自由、统制、改革及宗教派各有固定路线色，不再按列表序号分配。
- 每局设5—10个法官席位，包含一位首席；称谓依政体变化。扇形座席图显示五种倾向与人数，社会进步和政治自由两类合计少于半数。法官有独立姓名、关系与本案意愿。
- 所有修宪只从议会／最高人民会议／枢密院的议长或主席处提出。提出消耗1行动点，进入无专属行动选项的“宪法修订”局势；议会表决再消耗1行动点，院内支持率须至少三分之二。表决未过可继续协商，议案保留。
- 议会通过后启动三季度司法审查。每位法官意愿达到60时投赞成票，赞成票达到半数即自动成功（恰好50%也通过），无需再花行动点。第3季度开始时先核验票数，仍不足半数则自动失败并结束局势。所有政体均取消强行修宪；送审后不能撤回。若宪法已将最高司法权移交议事机关，则由该机关承担司法审查。
- 非民主国家（含象征性民主及一党独大制）固定提供“增加竞争性选举条文”。成功后，象征性民主／一党制转为总统制或半总统制；神权专制转为神权共和制或总统制；其他非民主政体转为君主立宪制或西敏议会制，每个结果各50%。保留季度、经济、人物身份与成果；重组执政联盟，失去入阁资格者按正常离任规则处理。转型后的竞争性神权共和制适用民主选举与任期规则。
- 所有新世界额外出现一个长期局势：“宗教少数派问题”或“少数民族问题”，各50%概率，不占普通模式一个／困难模式两个开局危机名额。未采取强制措施时不额外产生季度损耗。旧档补充一次，不追溯过往季度。
- 长期问题存在、尚未选择强制措施，且加权选票预测至少80%、政治稳定至少60时，在议长／主席处开放“社会多元修正案”。触发条件恰好达到也符合，提出后不再反复检查；完成议会三分之二及司法半数程序后解决长期问题。民主国家仅能通过此路径解决。
- 非民主国家可在长期局势中选择强制措施（1行动点），确认后不可撤回、切换、通过修宪提前终止或借政体转型取消。强制迁徙：信心立即一次性−20，从下一季度起持续20季度，每季支持−2、稳定−2、实际年化增长率−0.5个百分点。强制同化：从下一季度起持续25季度，每季支持−1、稳定−2、信心−0.5。局势展示剩余季度，期限届满产生结束报告，已发生的后果保留。
- 释宪流程保持原规则：通常会见最高司法机关首席；枢密院或已获最高司法权的议事机关在主席处提出。提出和表决各消耗1行动点，赞成须严格超过50%。可使任一公共预算上限增加1个百分点，为未启动改革每次减免原价25%的启动费（最多50%），或使指定党派关系增加10；通过时支持−1、稳定−2。枢密院可强行释宪，额外支持−8、稳定−8。
- 原有修宪条款保留：移交／恢复最高司法权、民主国家任期、经济模式、公民权利。司法权移交生效时司法独立−20、稳定−10、支持+10；任期可改为72季度或取消上限，保留选举和失政失败条件。
- 每位法官每季可互动一次：公开论证增加意愿12、关系3、独立1；无法院待审案时改为关系+6。秘密贿赂花费0.18% GDP、意愿+26；政治交换支持−1、稳定−1、意愿+20；司法压力独立−2、支持−1、意愿+24。本案加成持续至操作季度加3季度，结案后清除。贿赂／交换在下季度有3%／2%概率引发丑闻，施压有3%概率追加独立−10特别事件，不占常规三个事件名额。
- 国家档案、治国指南、本页教程与Wiki同步更新。旧存档保留行动点、历史、随机数进度和人物；已有修宪案免费转入议会阶段，保留已投入的关系和本案加成。升级前备份为 `nation-state-v1-pre-107-procedure`，首次补充司法系统的备份仍为 `nation-state-v1-pre-constitution107`。

实现入口：`constitution.js`、`constitutional-process.js`；当前显示版本 **1.0.7**，缓存版本 **1.0.7-office2**。
