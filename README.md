### 国家治理与任期基础

- 修正党派身份：每党只有一位党团总召或首席代表；四位议事机关负责人独立保留。
- 九种人物倾向、常规随机党名、七个按政体命名的随机地区；展示地区产业、地理、宗教、基本盘与发展。
- 地区票率由全国支持率、履约、发展与历史政策共同决定；按人口权重进行单轮两方多数决。
- 游戏历法为每年六季度、每届二十四季度。民主国家最多四十八季度；非民主国家四十八季度后可继续，每十二季度再次询问。
- 结算显示十二项完整历史图表，按决策（70%）与政策/指标（30%）生成九维画像，展示前三项倾向及契合度。非民主社会主义扩展列表由开局经济制度决定。
- 改革每六季度刷新未查看草案，保留已查看、已提交与执行中的项目。十九类改革包含国有化、私有化、一次性遗产税清债、主权基金、体育及文化投入。
- 每季度至少三个决策事件，涵盖经济、议会、地区、部长、司法、竞选、国际、安全、灾害、文化与体育。

注：这是简化的游戏模型。倾向契合度是游戏内部相似度，不是现实政治鉴定。

### 动态局势与执政压力

- 新世界新增困难模式：普通开局随机一个局势，困难开局两个不同局势，按政体加权；同种子同模式可复现。奥运、灾害、叛乱和民主化运动不会进入开局池。
- 新增局势页面：全国大罢工、司法公平事件、经济危机、政治丑闻、奥运筹办、重大自然灾害、叛乱、以国家简称命名的民主化运动。
- 局势具有持续效果、结束门槛、行动点成本、冷却、处置记录与结束事件；包含连续四季度预算承诺、工程延迟兑现、债务回表、救灾重建、调查问责、赛后场馆处置与民主转型选举。
- 一党独大制改为执政党主流派35席、新锐派22席、改革派25席、民主党派16席、无党籍团体2席；其他政体采用各自名称池，神权与世俗枢密院不再采用普通政党名称。
- 地方诉求每12季度轮换。当前已完成诉求不再重复出现，已排队事件同样检查；保存历史履约，灾区暂停原诉求惩罚。
- 每季基础支持损耗0.6、稳定损耗0.2，地方失信与财政压力追加损耗。危机叠加构成主要难度；移除试验版本的固定6点民意重罚。

### 内阁提案、科研与立法

- 大罢工紧急救济金取消季度冷却，可在同季反复使用，每次仍消耗 1 行动点与 2% GDP；公共工程改为四季度冷却和交付。前两项连续预算承诺保持原规则。
- 内阁十类职位各有持续提案、三个推进选项、投资折扣、能力与倾向加权。未完成每季主管忠诚 −1，选项忠诚 +1～3；换人保留进度，完成奖励不可重复领取。
- 教育现代化：师范设施基础费用 1.05% GDP/进度32，城市设施0.75%/24，乡村机构0.45%/16。实际进度 = 基础进度 ×（0.75 + 能力/200）× 契合加成（1或1.25）。费用按已通过预算折扣，最多优惠55%。
- 科研进度每季增加教育预算数值×2，教育现代化完成后×3。每100进度升一级，保留余数；每级增加1点季度政治行动额度，初始3点、最多6点。国家档案显示科研与额度。
- 议程倾向每季下降2点，玩家派系豁免；协商可抵消最多8点已积累损耗。预算全票门槛以60为基准：个税变化/1 + 消费税变化/1.5 + 企业税变化/2，再减各派系的公共投入偏好；执政党同样适用。
- 比例席位：折算倾向 = 原倾向 −（预算全票门槛−60）；50对应0%，51对应10%，60对应100%。席位保留小数权重；每个低于50的倾向点只在议案通过后扣除0.1稳定，另外保留原有通过收益。
- 民主与象征性民主政体只允许执政联盟人物入阁。其他党团关系达到70后，向该党总召发出联合政府邀请（1行动点）；非民主的其他政体保留全派系任命。每个派系12名候选人，人物倾向与派系路线关联。
- 可见比较符号改为“＞/＜”，相应局势结束门槛使用严格比较；前两项罢工预算承诺以“至少”表述并保持原机制，计时到期、100%完成与70关系组阁不改变。

### 地区、执政联盟与交互功能

- 一党独大制的议事机关统一改为“最高人民会议”，同步更新导航、说明、教程与指南。

- 简报按政体使用政务院、首相府、总统行政办公室等名称；总览简报只呈现施政相关消息。
- 执政提醒点击“知道了”后收起至可上下拖动的侧边按钮，点击可再次展开；位置和收起状态会保存。未解决风险仍保留红点，提醒数值实时更新，新问题首次出现时展开。
- 入门与本页教程支持空格进入下一步，长按不会连跳；按钮改为“空格进入下一步”，末步显示“空格完成教程”，继续支持左右键、鼠标和Esc。
- 创建世界改用十二种政体的插图卡片及随机选项，展示玩家身份、制度特点和行政机构，选中后可预览。图片使用玩家指定的十二张原图，卡片缩略图等比例裁切铺满边框，点击后在上方显示完整图片；西敏议会制更换为玩家新提供的横向图片。

- 创建世界新增固定、随机、伪随机三种行动点模式。固定模式每季3点，科研每级加1、上限6；随机模式每季投骰，科研每级将下限提高1，最高变为6—6；伪随机模式开局预排第1—48季度，1—6各出现8次并打乱顺序，每级科研叠加1点且允许超过6点。开局另发初始额度，超过48季度按种子续排。所有模式未用完不结转，同季刷新、导入和重复读取不重投。
- 教程拆分为左栏七步“入门教程”与右上方“本页教程”。入门只讲政体欢迎、受托机构、任期、目标、9维评估、治国指南与分板块学习方法；本页教程只介绍所选页面。行动点与科研说明随模式变化，继续支持高亮、键盘、跳过和返回原页面。

- 一次性遗产税特别征收改为清偿完成时现存公债的50%；GDP不变时，债务/GDP为70%会降至35%。每局限一次。
- 新增劳动部长/大臣，包含任命、季度任务、报告、辞职与更换。五种任务为自主判断、改善本部门财政、就业促进、劳动权益保障、劳资协商；部门提案“就业与劳动保障计划”有三项措施，受能力、倾向和公共投资加权，完成后失业率−0.7个百分点、支持率＋3、稳定度＋2。
- 补充政策利率说明、基准利率等搜索别名，在政策利率图表标题旁提供解释按钮。概念搜索忽略首尾标点，输入“政策利率、”也能找到条目。
- 民意与选举扩为七个非首都地区及一个独立首都地区。首都占12%人口权重，拥有自己的发展、履约、地方代表和选票，也可能遭遇城市洪涝。首都称谓随政体使用特别行政区、特别市、特区、大市或领地。
- 地名使用大量音节组合或地理词组合，局内唯一、同种子可复现。非首都地区增加邦、加盟共和国、特别市、特区等称谓；联邦地区可出现邦与加盟共和国，王室及枢密院政体使用领、自治领等。
- 权力构成改为与各派席位数量及颜色对应的100个座席。一般议会与最高人民会议为半圆图，西敏议会制和枢密院为两侧对坐图；图内没有文字，党派说明与协商按钮保留在下方。
- 民主国家新世界从席位严格超过25的党派中随机选取玩家党派，允许小于最大党；组阁、联合政府、季度倾向损耗和选后议席归属均使用实际玩家党籍，并显示“玩家所属”标记。

- 指标卡片支持鼠标点击与键盘打开居中的历史图表弹窗。国家档案新增与最终评估相同的十二项完整任期指标，按现有季度记录同步更新；第一条记录也显示数据点。任期评估仅在游戏结束后出现在导航中，进行中的图表查看转到国家档案。
- 治国指南移到开启教程下方，使用同等大小的明显按钮；教程同步介绍新的档案图表与提醒规则。
- 君主立宪制和西敏议会制新世界自动选择政策偏好最接近的非玩家党派作为政治盟友；不足50%席位时继续随机补充，直到联盟至少占50%。盟友初始议程倾向60，团体关系60至70，成员可入阁，并显示政治盟友徽标。其他民主与象征性民主开局仍为单党政府。
- 任意盟友关系低于50会触发政府危机，每季度支持率−1、稳定度−3。自触发起有三个季度恢复失信盟友关系至严格超过60，或按原来的关系达到70规则邀请新党派，组成至少50%席位的新联盟。该局势没有处置选项，只能前往议事机关协商。另组新联盟时，原盟友所属阁员全部辞职，逐人计入原有强制辞职后果与承诺违约计数。君主立宪、西敏政体逾期直接倒阁；其他支持联合政府的政体解散联盟并让盟友阁员离任，不直接触发游戏结束。
- 十一类提醒使用导航及相关指标/职位右上角红点：内阁空缺、未解决局势、加权选票低于50%、下季度将刷新的未查看改革、全国支持低于50%、稳定低于35、阁员忠诚低于35、失业超过8%、通胀超过45%、债务/GDP超过90%、司法独立低于30。风险解除后红点消失；每次问题新出现时弹出可关闭的执政提醒，提醒不进入强制决策队列，不阻碍季度推进。关闭提醒不会消除持续问题的红点。

### 五类税收与政体税制

- 税收政策由三项扩展为所得、企业利润、消费、土地财产、进口关税五类，每类均可独立调整、提交并表决。十二种政体使用相应称谓，例如臣民所得税、公司利得税、商品流转税、田产税、联邦个人所得税；名称差异不重复征税。

- 新税收同时接入收支、公债、实际增长、通胀、支持度与九维任期评估。财产税和关税以5%为中性基准：财产税每高1个百分点，增长目标−0.015、民意目标−0.12；关税每高1个百分点，增长目标−0.04×开放系数、通胀压力＋0.02、民意目标−0.1；宗教税每1个百分点使民意目标−0.25。通过后财政收支按新预算计算，实体影响沿用每季度35%的传导。

### 总统制与半总统制议会安排

- 总统制新世界在两党制、多党制之间各以50%概率抽取。两党制由自由主义或保守主义政党、社会自由主义或社会民主主义政党，以及倾向不同的无党籍党团组成；玩家属于两个主要政党之一。
- 两党制总统国家的两院使用相同三个党团名称，各院的关系、议程倾向和院内支持率独立计算。参议院否决预算案后，预算直接流案、现行预算继续执行；结构性改革只能退回众议院，复议通过后延缓两个季度实施。多党制总统国家沿用通常的复审、退回和延缓规则。
- 总统制随机75%设参议院、25%采用一院制；半总统制各占50%。创建新历史时，先明确选择总统制或半总统制，即可自行指定一院制、两院制，或保留随机。其他政体沿用各自院制。
- 一院制预算与改革通过本院后即可执行；修宪取得本院三分之二支持后，直接进入最高司法机关审查。
- 半总统制新世界至少有七个政党，议事机关随机称为众议院或国民议会。玩家所属党是相对较大的党派，也可能不是最大党。
- 半总统制开局与政治路线接近的党派组成至少50%席位的联合政府，联盟总数不超过三个党派；总理和阁员均来自联盟。盟友关系低于50触发三季度政府危机，期间每季支持率−1、稳定−3。恢复盟友关系至60以上，或按现有邀请规则组成新的多数联盟，可解除危机；逾期则联盟解散、盟友阁员离任并承担强制辞职后果，不因此直接终结玩家任期。

### 神职人员忠诚度

- 神权共和制的宪法监护委员会、神权专制的枢密院新增神职人员忠诚度，初始为100%。
- 法案在相应议院通过时，宗教党派或神职团体对本案的倾向低于60，则按差额扣除忠诚度：55扣5，56扣4。多个神职团体的差额累计；宪法监护委员会全部由教士组成，各团体均计入。预算使用包含税收与公共支出偏好的本案折算倾向，上院计入临时协商加成。
- 忠诚度低于40时，每季度全国支持率−1，并出现执政提醒；低于20时，每季度全国支持率−1、政治稳定−2，两档惩罚不重复叠加。
- 神权专制忠诚度归零时结束统治；神权共和制归零时触发叛乱，平息叛乱后，无论通过安全行动或谈判，国家转为象征性民主制，随后组建参议院、补齐内阁空缺。
- 忠诚度的阶段后果、最近法案扣减记录默认收在“查看忠诚度细则”中；治国指南补充院制、党制、半总统制组阁与神职忠诚度条目，管理员控制台可调整忠诚度进行测试。

### 贵族制家族政治

- 监察机构新增与枢密院并列的“家族互动”。随机生成4—6个来自不同地区的贵族家族，玩家随机属于一家；15项产业和机关势力按地区特征分配，全部势力都有归属。
- 玩家家族合法性承认固定100，其他家族初始80—100。承认达到40或更低时，每家每季全国支持率−0.5、稳定−1；低于20暂停枢密院表决；三个仍有势力的家族承认归零时统治结束。低于80的承认会降低关联派系议程倾向，多家影响累加；自治市民与教士派系占比较低且不参与家族勾连。
- 每季度增加一件其他活跃家族的要求事件，内容与其势力有关。接受可能需要财政支出、支持、稳定、中央集权度或承受通胀；拒绝使该家族承认下降。常规三件事件保留。
- 可分化继承人集团、贿赂内部人员或同家族结盟。贿赂成功率随全国支持率从50%升至100%，获得材料后可以要挟或公开调查。公开调查夺取的一项势力转入玩家家族，失去全部势力的家族退出互动及全部家族负面影响计算。
- 家族页面和执政总览显示中央集权度：从0起算，玩家每项家族势力加5；最高司法机关、公民权利、社会多元修宪生效每案加10；国家投资统筹、文化、科研网络、数字行政、国有化、主权基金、防务和普惠医疗改革完成每案加5。
- 达到100触发“重新决定国家未来”。无需行动点，可选择保留贵族制并停止家族合法性与中央集权计算，或转为君主专制、君主立宪制。保留经济与执政历史，转型后的内阁、两院和选举按相应制度运行。
- 所有政体移除经济模式修宪；贵族制移除竞争性选举修宪，改由国家未来局势决定制度转型。家族阈值、互动代价、改革影响与历史记录默认折叠，治国指南与本页教程补充对应内容。
